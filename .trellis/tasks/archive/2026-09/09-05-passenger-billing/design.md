## 边界与所有权

- `internal/carpool/pricing`：内置目录、精确价目解析、原子版本、更新状态、冻结价格计算。
- `internal/carpool/billing`：金额输入/格式化、纯函数账期、进度与未知覆盖投影。
- `domain`、`store/sqlite`：递增迁移、成员限额、账期汇总、事件计价、幂等事务、升级恢复。
- `runtime`、`service`、`httpapi`、`module`：授权事务接入、模型价校验、安全错误码与 DTO。
- `sdk/cliproxy/usage`、`sdk/cliproxy/executor`、`sdk/cliproxy/auth`、`sdk/api/handlers`：
  仅添加可选请求级钩子和所有执行分支的传递，未启用拼车时无影响。
- `internal/runtime/executor/helps`：仅当最终模型信息或安全用量投影确实需要时补最小支撑，
  不在 executor 根目录放 helper，不复制 provider Token 规则。
- `web/assets`、`internal/config/carpool.go`、配置镜像/示例：限额输入、车内金额进度、目录配置。

## 核心不变量

1. 金额以 nano-USD 整数存储，API 十进制字符串；比较不用浮点。每事件只舍入一次。
2. 请求授权固定成员、scope、账期、价格目录；重试不能扩 scope 或换用新目录。
3. 实际模型解析/插件改写后必须经过价格校验，缺价不进入对应上游，也不惩罚账号健康。
4. 同一 CPA 事件只计算一次；事件插入与期累计同事务，金额不从可删明细重新汇总。
5. 复用 canonical Token 桶，缺必要维度时未知；unknown 与已确认零不同。
6. 已开始请求不因后来调额或达额中断；当前期重置抵消已经确认的累计，后到事件仍正常记账。
7. 新成员无默认不限额；升级成员 NULL 待设额、原锚点保留、历史未计价，不追溯扣款。

## 风险与回滚

最高风险是共享 SDK 钩子绕过、异步用量丢失、账期漂移、隐式浮点、删除明细影响限额和
真实模型缺价却连接上游。必须先写确定性回归再联调，不能用界面截图代替金额正确性验证。
新迁移不可直接用旧二进制回滚；仅在隔离库验证，正式升级前停机备份，恢复另行确认。

## 当前修复的最小技术边界

1. 模块启动沿用 `RecoverInterruptedRequests` 标记中断，不从历史 incomplete 初始化
   运行中记账健康状态；删除仅服务全局启动封锁的查询/配置接线。已有未知展示复用。
2. writer 继续同步尝试写入，固定容量缓存只存安全事件及冻结的待写费用；满缓存
   阻塞当前回调，单一重试驱动恢复后唤醒。锁不能阻止新请求快速得到运行中 503。
3. 模型读取的非计费 completion 走现有非计费/best-effort 队列，不占计费 pending。
4. 插件流收尾先发布 usage 再 completion；不修改 provider 返回/取消生命周期协议。
5. 清理现有 SQL 条件统一排除 in_progress/incomplete，并保护其事件和账期；不新增
   状态、schema、outbox、恢复工具或价格算法。
6. 用失败注入与 channel 屏障验证小容量等待/唤醒，重启允许新生成但保持中断提示，
   以及清理保护。crash 精确恢复和等待者总体数量不是此轮承诺。

被否决的扩大方案仅存于 `research/withdrawn-settlement-proposal.md` 供追溯，不加入
实现/检查上下文。修改以本文件开头的最新用户决定为准。


## 剩余交付技术边界

- 授权时取得一次价格目录快照，同一目录用于请求 hash、执行前检查和后续事件计价。
  重试及异步兼容投递不能读新目录；请求完成即自然释放引用，不建立持久化 outbox。
- 可选 SDK 请求级校验在实际模型解析/插件改写后、每次 executor 调用前执行。
  缺价本地返回 `422 model_price_not_configured`，不连接该上游、不增加账号冷却，
  不扩大 scope；模型查询和旧全局 Key 保持行为。复用 CPA 现有模型映射/后缀语义。
- 沿用独立计价与互斥 Token 桶；只修本次价格快照相关可复现缺陷，不重写计价系统。
- 浏览器使用真实 Go 路由、隔离 SQLite 和假上游计量。桌面1440、移动390/360、
  200%放大检查改密、上车调额、消费、明细/筛选/分页、清理确认、错误及旧页面边界。
  截图/用例为模拟上游证据，不是生产供应商账单证明。沿用 DESIGN.md 的 B 方向。
- 浏览器发现真实阻断时只做对应 UI/API 小修；不重新设计、不隐藏失效操作。
- 最终独立检查与全量 test/vet/race/两种构建，整理升级/限制/验证发布说明。
  本地完成提交和任务归档，不推送远程、不部署生产、不修改真实配置/凭据/数据库。

## 定向验证

```bash
gofmt -w .
go test ./internal/carpool/... ./internal/config
go test -race ./internal/carpool/...
node --check internal/carpool/web/assets/app.js
go build -o test-output ./cmd/server
```

遵守父计划的输出路径安全规则。数据库测试包括：同一 started_at 的多行稳定游标、
新记录插入、模型同时匹配请求/事件、一个请求上千事件的有界删除、当前期被清理但仍拒绝
新请求、删除历史期后旧明细仍可读、重置后重复 event 不恢复旧费用、跨月预览失效。
浏览器完成筛选/展开/回退恢复与三种操作的预览、取消、确认和失败；只使用测试数据。

## 回滚点

先完成账本独立性和无在途证明，再接删除入口；任何累计变化回归未解决不能上线清理。
UI 出错不自动重发危险操作，通过服务端确认引用查询已完成结果。清理数据只能从备份恢复，
恢复不是自动重试的一部分。

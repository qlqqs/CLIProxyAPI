# 拼车额度工作台：四方向设计样机

打开 `index.html`，或访问当前局域网预览服务：

`http://192.168.50.206:39987/`

同一台机器也可使用 `http://127.0.0.1:39987/`。

这里比较四个独立方向：

- A「日光调度台」：浅色协作台，一条连续预算轨道串起余额、账期和成员状态。
- B「暗色仪表台」：夜间监测席位，用等宽数字和分段刻度呈现阻止、未知和上游窗口。
- C「精密账页」：连续账页与可展开 CPA 事件，重点是费用来源可核对。
- D「交通导视」：车次带与座位顺序，黄色只承担身份和主操作，超额成员直接可见。

拨动顶部的「视觉冒险度」「动效强度」「信息密度」后，点方向底部按钮进入确认弹层；只有确认后才会写入同目录的 `selection.json`。当前样机只使用虚构数据，不连接产品 API 或数据库。

## 现物提取与诊断

现有系统：底色 `#0f1418`、工作区 `#151c21`、浮层 `#1c262c`，主文字 `#edf4f3`、青绿色强调 `#73d2bf`；系统中文与等宽数值；18–24px 容器圆角，10–12px 控件圆角；表格采用 14px × 15px 单元格内边距，弱边框与单层阴影。顶栏最小高度 76px，横向导航可折行。

按代码可观察到的影响排序（运行截图另行记录）：

1. 管理端九个一级入口与品牌、标题、用户区共享横向顶栏，且导航允许折行。需要按「运营」「分析」「系统」分组，降低窄桌面上的导航拥挤。
2. 管理概览目前仅显示用户总数、车辆总数、模块状态、时区，缺乏业务入口和操作优先级。建议把高频管理动作与异常入口放进主工作区；需要聚合数据时必须确认现有 API 可提供，不能虚构后端能力。
3. 用户额度区首先突出已用金额，剩余与重置时间位于小字中。建议先回答「还能用多少、是否可用、何时重置」，保留未知费用与覆盖范围语义。
4. 通用表格最小宽度为 760px，多类数据共用横向滚动。窄屏需按页面选择摘要行、详情展开或局部滚动，而不是全表缩小。
5. 两端复用视觉骨架，但高频目标不同。管理端需要列表管理与排查，用户端需要个人额度与接入；共享设计令牌，不强迫共享信息布局。

## 不可破坏的功能契约

- 额度为 USD，不新增充值、支付或汇率；剩余额度、已确认费用、限额、账期与未知费用不能混淆。
- 乘客额度与 CPA 原生账号窗口严格分离；缺失显示「上游未提供」，不得伪造 0%。
- 保留鉴权、角色权限、CSRF、Key 一次性展示、改密门禁、清理预览与确认。
- 页面、表单、弹层、长文本、空态、加载、错误、成功、移动端与键盘路径均纳入后续实现范围。

## 四方向隔离 brief

- A 晴昼工作台：当代生产力工具；冷白与石墨，蓝色动作；无衬线数值；分组侧栏与表格工作区；中密度。硬约束：不采用深色整体背景或顶部堆叠全部入口。
- B 信号控制室：工业仪表；近黑、琥珀注意色；等宽数值；窄轨导航、队列与详情主从区；高密度。硬约束：不使用柔软圆角卡片或展示型大留白。
- C 纸上账本：复古编辑印刷；纸白、墨黑与陶土；衬线金额与系统中文；章节索引、开放双列和水平规则线；低中密度。硬约束：没有永久侧栏、没有封闭圆角卡片墙。
- D 随行空间：掌上消费工具；鼠尾草绿与柔和暖色；人文无衬线；任务分区与底部导航；低密度。硬约束：不使用传统企业后台侧栏或密集监控表。

本次没有媒体资产需求：布局、字体角色、数据层级和交互位置即可表达差异，不引入图片、外部字体或外部模型。

## 本机运行

```bash
node .agents/skills/qiaomu-design/scripts/qiaomu-design-preview-server.mjs \
  --file design-previews/2026-09-14-carpool-full-redesign/index.html \
  --no-open --exit-on-select
```

当前机器没有 `xdg-open`，Paseo 未连接浏览器宿主，不能自动弹出用户浏览器；必须使用 `--no-open` 启动后手动打开终端输出的地址。默认自动打开参数会因缺少启动器而退出，此问题仅记录为运行环境限制，未扩大本次改版范围去修改技能运行时。
